# Project guidance

- This is an expert tool, not a marketing site. Users return often to explore permutations; optimise for density and repeat use.
- Keep chrome minimal: one compact sticky toolbar, no hero, no large headlines, no explanatory prose on screen. Put explanations in tooltips or the footer.
- Controls in toolbars are compact (32–36px segmented controls), not chunky pill tags.
- Context (standings, pool info) sits to the right as margin notes; matches are the main column.
- Stage flow is Pools → Knockout; Knockout stays locked until all pool matches are picked.
